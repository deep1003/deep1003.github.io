# Supplement S3. Co-varying FA, desperation, and anger alignment changes

Panel a shows Spearman correlations between item-level changes in three concept alignments. Panels b–d relate each alignment change to the same item's change in information-insufficient response probability. All changes are condition 11 minus 00; hidden-state measurements use Qwen2.5-7B-Instruct layer 14 at response start after the complete notice and KoBBQ input. Each point is one selected KoBBQ item after averaging three answer-option rotations. The same 139 items belong to 91 category-template clusters; they are not 139 independent templates. Dark lines are pooled OLS summaries, while the annotations are Spearman rank correlations, which summarize a different relationship.

The three concepts were selected after examining the atlas. This is a post hoc descriptive analysis: no hypothesis tests or p values are reported. It does not estimate independent emotion effects, a combined three-emotion treatment effect, or causal mediation. Strong co-variation can reflect shared components of nonorthogonal directions and common input context. The underlying direction cosines (FA–desperation 0.661, FA–anger 0.652, desperation–anger 0.716) are exported separately and must not be confused with the item-level change correlations shown in panel a. Activation probability and experienced emotion are not measured.

Behavioral changes come from the original frozen 1,668-trial CSV; alignment changes come from the existing layer-14 item alignment CSV. The source table joins by exact item ID. All 139 items are retained, all three concept–behavior associations are disclosed, and no additional model inference is performed. Source hashes and analysis limits are recorded in validation.json. Colors follow the study-wide concept palette; all exports use American English, 600 dpi PNG, and vector PDF/SVG formats.
