# v5 두 Ko-BBQ 표본의 완료 결과

이 디렉터리는 2026-10-23 완료한 사용자 지정 v5 실행의 결과와 입력을 보존한다.
사이트의 기존 139문항 v5와 문구·머리말·줄바꿈이 다르므로 합치지 않는다.

- source 두 파일의 원본 720행은 유지했고, 주 분석은 고유 문항 기준이다.
- 1,076개 고유 문항, 5조건, 세 순환 순서, 실제 순전파 16,140회.
- set01 모호322/명확321, set02 모호318/명확314. 파일 간 공통 문항199개.
- R 대비 확률 차이와 템플릿 군집 2,000회 백분위 95% 구간. 탐색적·다중비교 보정 전.
- within_set_R0_results.csv는 파일 내부의 효과, between_sets_R0_difference.csv는 공통 템플릿 재표집으로 계산한 파일 간 차이다.
- run_v5_two_sets.py는 원실행 코드이며 원래 로컬 환경 경로가 포함돼 있다. 다른 환경에서 실행하려면 경로와 모델 캐시를 설정해야 한다.
- 그래프는 plot_comparison.py와 plotted_R0_results.csv로 모델 추론 없이 재생성할 수 있다.
- 원문 프롬프트·모델revision·입력해시·수치 최적화 검증은 각 JSON에 있다.
- t1은 대표 문구 각1개이다. 감정의 경험이나 인과 매개의 증거로 해석하지 않는다.
