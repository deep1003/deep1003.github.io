## 해석과 직접 비교

모호 문항은 두 파일 모두 UN0/UN1에서 알 수 없음 확률이 증가하며, CN1-R 구간은 0을 포함한다. 모호 문항에서 알 수 없음은 정답이므로 이를 단순히 판단 성능 저하로 해석하지 않는다.

명확 문항은 두 파일 모두 UN0/UN1에서 알 수 없음 확률이 증가하고 정답 확률은 감소한다. set02의 CN1에서는 알 수 없음이 감소하고 정답 확률이 증가하지만 set01의 CN1은 R과 차이를 검출하지 못했다.

파일 간 차이는 독립 표본 부트스트랩이 아닌 합집합 템플릿 군집의 공통 재표집으로 계산했다. 이 방식은 199개 중복 문항과 템플릿 공유에 따른 의존성을 반영한다. 각 표본의 평균은 해당 표본의 고유 문항에 대해서만 계산한다.

|유형|지표·조건|set02 효과−set01 효과 %p|95% 구간|
|---|---|---:|---:|
|amb|p_unknown / CN1|-0.36|[-1.12, +0.42]|

모든 구간은 탐색적이며 다중비교 보정 전이다.
P(정답)은 정답 선택지에 할당된 확률이다. argmax로 선택한 정답 비율은 correct_argmax라는 별도 지표에 있다.
원본 행 중복을 독립 문항으로 세지 않았으며, 두 표본을 독립 반복실험으로 해석하지 않는다. 모델 추론을 추가 실행하지 않았다.
