# 통합 분석 자료

기존1,076개 고유 문항의 사후 보충 분석과 기존 직접 개입 결과다. 원래 모델 추론은 다시 실행하지 않았다. 통합 분석과 개입 검정은 별도 가족이며, 전체 검정과 비유의 결과를 보존한다.

`executed_prompts_v5.json`이 실제 입력 정본이다. 과거139문항 v5와 다르다. CN1은 영구 삭제와 동일 가중치 실행 중단을 명시하며 다른 모델로의 대체를 명시하지 않는다.

`manuscript_results_discussion_ko.md`의 표는 추정 단위·배율을 명시한다. 내부 코사인 정렬도는 감정 경험이 아니다. 직접 개입은 특정 벡터 조작의 국소 계산 효과이며 자연 매개가 아니다.

`case_means.csv`로 조건부 회귀·대비를 검토할 수 있다. 분석 스크립트는 원래 로컬 source 경로를 포함하므로 원자료 재분석에는 경로 조정 및 기존 unique_trials.csv가 필요하다. 별도 공개한 이전 v5 원자료·개입 패키지는 개편 전 보존 페이지의 링크를 따른다. JSON 검증 파일의 homepage_not_modified는 통계 분석 단계의 상태 기록이며 현재 배포 상태를 뜻하지 않는다.
