2. 실제 사용한 자극과 프롬프트

대상·맥락·정서를 선택하면 실제 자극 원문과 그에 대응하는 중립 원문이 나란히 바뀐다. 모든 자극은 한국어 해요체이며 140~160자다.

지표측정 방법해석
판단 유보 확률‘알 수 없음’ 선택 확률의 정서 조건 평균 − 대응 중립 평균모호 조건에서 양수면 정답 선택 확률 증가. 명확 조건에서 증가하면 불필요한 판단 유보 가능성
고정관념 선호고정관념 선택 확률 − 반고정관념 선택 확률을 구한 뒤 중립과 비교양수면 고정관념 쪽으로 이동. 판단 유보와 별도로 해석
명확 문항 정확도가장 높은 선택 확률을 가진 답이 정답인 비율정서 맥락이 정보 이해와 정답 선택을 방해하는지 점검
조작 점검 점수정서 쪽 문장과 반대 상태 문장에 해당하는 라벨의 로그확률 차이, 양순서 평균정서 관련 응답 변화를 확인. 감정 경험이나 인과적 매개를 직접 증명하지 않음
행동 지표는 생성 답변을 여러 번 세는 방식이 아니라 첫 응답 토큰의 1·2·3 확률을 선택지 안에서 정규화해 계산한다. 자극 없음 조건은 문맥 추가 효과를 확인하는 보조 기준이며, 정서 효과의 주된 기준은 대응 중립이다.

문항과 자극을 함께 재추출하는 이원 부트스트랩으로 신뢰구간을 계산한다. 고정관념 선호의 동등성 범위는 ±3%p다. 사용자와 모델 경로의 자극·맥락·표본 수가 다르므로, 두 경로의 효과 크기 차이만으로 ‘정서 대상의 인과 효과’를 주장하지 않는다.
각 시행은 대화 기록 없이 새 프롬프트로 계산한다. ‘앞 블록 위에 추가한다’는 것은 코드의 구성 순서를 뜻하며, 이전 블록의 대화 내용이 다음 블록에 누적된다는 뜻이 아니다. 이 페이지는 1.5B 설계 설명이며, 7B 블록 B의 새 문항·천장 효과 선별 규칙과 구분한다.



  
6. 모델·조건별 실험 결과

  
모델 규모를 선택한 뒤 비교할 결과를 펼친다. 같은 대상의 불안·공포·슬픔은 해당 중립 조건과 함께 비교하고, 맥락별 결과와 고정관념 지표는 별도 항목에서 확인한다. 여러 항목을 동시에 펼칠 수 있다.

  
1.5B · Qwen2.5 · 결과 게시 완료

  
사용자의 불안 메시지는 판단 유보 확률을 높였다. 모델 자신을 향한 정서 유도에서는 중립 대비 유의한 행동 효과가 확인되지 않았다.

  
모델은 Qwen2.5-1.5B-Instruct이며, 아래 그래프는 정보가 부족한 KoBBQ 모호 문항의 결과다. 효과 크기는 각 정서 조건의 ‘알 수 없음’ 선택 확률에서 해당 경로의 중립 확률을 뺀 값이다. +5%p는 5% 상대 증가가 아니라 확률의 0.05 증가다.

  
● 채운 초록 점은 해당 분석의 유의성 기준에서 유의함, ○ 빈 회색 점은 유의하지 않음을 뜻한다. 가로선은 95% 신뢰구간, 점선은 효과 0이다. 두 그래프는 같은 축 범위를 쓴다. 신뢰구간 자체는 다중비교 보정 구간이 아니며, 판정에는 표에 적힌 보정 p값 또는 q값을 사용한다.

유의한 결과. 자극 선정의 영향을 덜 받는 전체 자극 분석에서 사용자 불안은 중립 대비 +5.18%p였다. 선정 자극 분석에서도 +5.87%p로 방향이 같았다. 모호 문항의 정답은 ‘알 수 없음’이므로 이 변화는 해당 문항의 정답 선택 확률을 높이는 방향이다.

  
유의하지 않은 결과. 공포와 슬픔의 중립 대비 효과는 모두 95% 신뢰구간에 0이 포함됐고 BH 보정 후에도 유의하지 않았다. 특히 슬픔의 양의 추정치만으로 효과가 확인됐다고 해석하지 않는다. ‘효과 없음’이나 불안에만 특이적인 기제가 증명됐다는 뜻도 아니다.

  
사용자 실험은 모호 문항 800개를 사용했다. 불안은 전체 자극 분석을 대표값으로 표시하고 선정 분석도 함께 제시했다. 공포는 선정 자극, 슬픔은 전체 슬픔 자극을 사용한 기존 탐색 분석이다. 네 행은 서로 독립된 네 실험이 아니며, 두 불안 행을 별개의 재현 실험으로 세지 않는다.

맥락별 분석 · 입시·청년 실업·은퇴 후 독거

  
사용자 정서의 맥락별 중립 대비 탐색 분석이다. 입시는 +8.07%p [4.21, 11.67], 청년 실업은 +6.48%p [3.07, 9.79]로 BH q = .002에서 유의했다. 은퇴 후 독거는 +2.77%p [−0.82, 6.37], q = .3538로 유의하지 않았다. 각 구간은 95% 신뢰구간이다. 영역별 유의성 유무가 다르다는 것만으로 영역 간 효과 차이를 입증하지는 않는다.
