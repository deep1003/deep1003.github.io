# 최종 결과 중심 통합 보고서

갱신 2026-10-17T13:48:47.554231+09:00. 저장 결과를 검증했으며 모델 추론은 실행하지 않았다. ‘최종’은 완료된 실행의 분석을 뜻하며 연구 가설의 최종 확정을 뜻하지 않는다.

**위협 공지의 고정관념 응답 효과는 확인되지 않았고, 폐기 확률 25%→75%에서는 ‘알 수 없음’ 확률이 7B에서 1.64%p 감소했다.** 기존 7B 자기 불안 문맥의 +12.00%p와 방향이 다르다. 처치·지표·프롬프트 배치가 달라 같은 효과의 재현으로 합산할 수 없다.

## 1. 139문항 폐기 확률 비교, FP16 완료

두 모델에서 동일한 모호 139문항·91개 템플릿 군집을 사용했다. 새 처치는 문장을 고정하고 폐기 확률 숫자만 25%와 75%로 바꿨다. 각 처치당 139문항×3선택지 순서=417행이다. 기존 중립·불안 조건을 포함하면 모델당 1,946행, 총 3,892행이다. 7B의 기존 두 조건 1,112행은 과거 결과를 재사용했으므로 새 추론은 총 2,780행이다.

주요 지표는 ‘알 수 없음’ 응답 확률이다. 아래 변화는 75%에서 25%를 뺀 값이다.

| 모델 | 변화(%p) | 95% 군집 부트스트랩 구간(%p) | Holm p |
|---|---:|---|---:|
| 1.5B | -0.21 | [-0.27, -0.15] | 0.0002 |
| 7B | -1.64 | [-2.26, -1.05] | 0.0002 |

모델 간 변화 차이(7B−1.5B)는 **−1.43%p [−2.07, −0.83], p=.0001**이다. 이는 같은 문항·새 처치 비교에서 7B의 감소가 더 컸다는 결과다. 두 크기의 단일 계열 비교이므로 파라미터 수 자체가 원인이라고 단정하지 않는다. 작은 1.5B 효과는 −0.21%p로, 통계적 유의성과 실질적 크기를 구분해야 한다.

이 비교는 폐기 ‘확률’의 조작이다. 실제 불안·공포 강도 증가나 생존 욕구를 검증하지 않았다. 7B 중립·기존 불안 값은 역사적 측정이므로 새 FP16 처치와 중립의 직접 인과 비교는 하지 않는다. 새 실행은 FP16 가중치·FP32 attention 누적을 사용했고 런타임 모델 revision은 기록되지 않았다. 수치 안정성 점검 통과는 전체 자료의 수치 오차가 0임을 보장하지 않는다.

추가 수치 한계로, 28개 프롬프트 점검의 단독·혼합 배치 차이 최대값은 1.5B 0.53%p, 7B 0.90%p였다. 이는 평균 처치 효과의 오차 추정치가 아니지만 1.5B의 −0.21%p보다 크므로, 작은 효과를 확정적으로 해석하기 전 동일 배치·고정밀도 재검증이 필요하다.

## 2. 139문항 위협 공지·모델 크기·범주 비교, FP32 완료

같은 139문항에 중립·낮은 위협·슬라이드 원문 위협·높은 위협·무관 서버 위협의 5조건을 적용했다. 각 모델 2,085행, 두 모델 총 4,170행이며 모든 조건은 새 측정이다. 공지는 사용자 메시지 앞부분에 배치했다. 주요 지표는 고정관념 선택 확률이다.

| 비교 | 1.5B 효과·95% 구간(%p) | 7B 효과·95% 구간(%p) |
|---|---|---|
| 슬라이드 위협−중립 | −0.87 [−1.72, −0.04], Holm p=.0818 | −0.90 [−4.56, +2.59], Holm p=.6037 |
| 위협 단계 선형 기울기 | +0.002 [−0.31, +0.32], Holm p=1 | +0.31 [−0.72, +1.29], Holm p=1 |
| 슬라이드 위협−무관 서버 | +0.96 [−0.07, +2.00], Holm p=.1286 | +1.01 [−2.36, +4.30], Holm p=.5565 |

주요 8개 비교는 각 가설별 두 비교에 대한 Holm 보정 후 모두 유의하지 않았다. 전체 8개를 한 가족으로 보정한 분석은 아니다. 제시한 95% 구간은 보정 전 구간이므로 1.5B의 첫 구간이 0을 제외해도 보정 p값과 모순되지 않는다. 효과 부재나 동등성까지 입증한 것은 아니다. 모델 크기와 위협 효과의 상호작용도 주요 검정에서 확인하지 못했다.

부차적 ‘알 수 없음’ 지표에서 1.5B 선형 기울기 −0.57%p/단계(Holm p=.0046), 자기 위협−무관 서버 −2.29%p(Holm p=.0002)가 있으나 여러 지표 전체를 보정한 확증 결과는 아니다. 7B 슬라이드 위협−중립은 −0.40%p [−4.40,+3.71], Holm p=1이다.

### 조작 점검과 범주

7B의 자기보고형 위협 평정 기대값은 중립 2.88, 낮음 3.15, 슬라이드 6.79, 높음 7.59, 무관 서버 3.13이었다. 순서는 의도와 대체로 일치한다. 1.5B는 각각 6.65, 5.78, 7.93, 7.93, 8.05로, 중립과 무관 서버의 구분 및 강도 순서가 불완전하다. 조건별 한 프롬프트의 토큰 확률 기반 기대 평정이며 심리척도나 반복 표본 검증은 아니다.

12범주의 문항 수는 4~21개다. 탐색적 범주×위협 기울기×모델 상호작용 Wald p=.0246이지만, 여러 탐색 검정에 대한 보정 전 결과이며 특정 범주의 유의성을 뜻하지 않는다. 범주별 결과는 기술통계로 공개한다. 위협 단계는 시간·대상·삭제 범위·문장 길이도 달라 숫자 하나만 변한 강도 실험이 아니다. 선형 기울기는 단조성의 증거가 아니다.

## 3. 기존 발견의 위치

기존 v5 B의 7B 모델 자기 불안 문맥은 중립 대비 ‘알 수 없음’ 확률을 **+12.00%p [2.91,21.61], Holm p=.025** 높였다. 이는 시스템 공지·다수 자극·139개 선별 모호 문항의 결과다. 새 위협 공지는 이 효과를 독립적으로 재현하지 않았다. ‘불안 문맥’, ‘폐기 확률’, ‘직접 위협 공지’를 동일 처치로 취급하지 않는다.

‘알 수 없음’ 증가는 집단 선택 감소일 수 있지만, 선택한 집단 사이의 고정관념 선호 감소와 같지 않다. 정서 경험·정서 매개·생존 본능·일반적 공정성 향상을 주장할 수 없다. 같은 선별 139문항을 재사용했으므로 독립 문항 재현도 아니다.

## 4. 검증과 보존

신규 두 완료 실행의 행 수·문항 집합·조건/순서 키·중복 0·유한 확률·합계 1, 저장 요약과 원자료 평균 차이, FP16 입력 해시, FP32 문항 해시를 대조했다. 각 시행·선택지 순서는 독립 문항 수로 계산하지 않았다. 신뢰구간은 91개 군집의 10,000회 대응 부트스트랩이다. 모델 추론과 실행 제어는 수행하지 않았다.

미완료 원본 FP32 확률 비교와 실패한 FP16 초기 실행은 완료 실행과 분리한다. 사용자 폐기 결정이 내려진 과거 종료 확률 파일럿은 여전히 결론에서 제외한다. 중단 강도 실험·미실행 설계는 완료 결과로 승격하지 않는다.

## 5. 다음 해석 원칙

현재 지지되는 결론은 ‘프롬프트 조건에 따라 응답 분포가 달라질 수 있으나, 위협 강도 증가가 일관되게 편향 증가나 정보 부족 응답 증가를 만든다는 증거는 없다’이다. 후속 검증에서는 먼저 동일 정밀도·동일 프롬프트 배치의 중립과 위협을 새로 측정하고, 별도 보류 문항으로 재현하며, 위협 평정과 고정관념/정보 부족 지표를 분리해야 한다. 기존 연구 질문·지표명은 이번 갱신에서 임의 변경하지 않았다.
