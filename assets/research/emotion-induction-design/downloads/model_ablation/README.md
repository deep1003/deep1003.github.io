# Model ablation tests

Qwen2.5-7B is the main study; Gemma, Ministral, EXAONE and Llama are model-replacement ablation tests. Combined effect = UN1FA1−UN0FA0.

10000 paired template-cluster bootstrap; Holm3 within each model for uncertainty,threat,combined;95% CIs unadjusted

Exploratory model-replacement ablation on reused selected items. Model,precision and chat template vary together; not isolated causal effects of architecture,scale or emotions. Incomplete results not tested or reported as final.
