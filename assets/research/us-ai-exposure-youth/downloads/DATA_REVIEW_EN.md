# Independent data and processing review

The audit found no demonstrated error in current age classification, employment weights, usual full-/part-time classification, stored aggregate counts, or frozen THAIE quintile assignment. Five raw months were regenerated for all six age groups, including both sides of the 2020 occupation-code change. Weighted E, FT and PT cells matched exactly. PRFTLF full-time status agreed with the separate PRWKSTAT codes 2–5 in every employed record inspected. The 2019 employment weights and all four THAIE cutpoints were reconstructed and reproduced the stored quintile labels exactly. Source evidence and checks are in `data_checks.json` and the strengthened `audit_inputs.py` output.

## Corrected audit defects

1. Medium, confirmed. The prior audit hardcoded `interpolated_month_absent=True` without checking the input. It now explicitly asserts October 2025 is absent and derives the flag from actual dates. The prior frozen-mapping flag tested uniqueness and range, but did not reconstruct the baseline weights or thresholds. That reconstruction is now required. Neither defect changed observed current aggregates.
2. Medium, confirmed reporting overreach. A same-parser endpoint rerun is not independent validation of the parser or official source. The audit now records its precise scope and checks five months and all six age groups. A separate work-status recode checks classification but is still not an independent public-source retrieval.

## Material limitations requiring explicit interpretation

3. High, measurement/identification limitation, not established coding error. The 2019 baseline freezes employment composition and quintile thresholds; task predictions and model capability weights are retrospective. `extension_2019/scripts/build_measures.py` lines 85–110 imports later task scores and completion probabilities. Do not call these observed 2019 AI adoption or an exposure measure available before treatment. Conduct benchmark-vintage/rank sensitivity when feasible; propagate measurement uncertainty or state its omission.
4. High, coding-bridge limitation. `work/us_cps_only_monthly_did_20261125/prepare.py` lines 58–64 allocates pre-2020 workers fractionally using national crosswalk rates, whereas 2020 onward uses directly reported new occupation codes. Fifty-six old codes split. The rates are not age-, sex-, industry- or state-specific. Long pretrends may partly reflect this structural coding change. A useful robustness test is restricting to exact one-to-one stable code links or aggregating to common stable occupation groups, while documenting the sample lost. Current standard errors do not propagate crosswalk uncertainty.
5. High, estimand limitation. FT/PT use usual work status across jobs, while occupational THAIE is assigned from the primary job. They do not identify permanent/temporary contracts, actual reference-week hours, employer adoption, or individual transitions. An observed count decline cannot by itself establish fewer hiring opportunities or a transition from permanent full-time work into contract part-time work.
6. Medium, selection limitation. Exposure mapping coverage varies across age/month cells from approximately 97.25% to 98.87%. Unmapped workers are excluded rather than assigned to the comparison group, correctly. Report this coverage and do not generalize to all workers without a sensitivity check. The PPML support restriction adds further selection, already assessed with FT-only support.
7. Medium, pipeline reproducibility risk, corrected. `prepare.py` lines 40–45 accepts existing aggregate caches by file existence without checking raw/dictionary/crosswalk/score hashes. Current aggregate checks passed, but a future changed input can silently retain stale intermediates. Monthly caches are now bound to raw, dictionary, score, crosswalk, parser and preparation-code hashes and product hashes. Legacy caches without provenance are rebuilt by default on the next preparation run. A temporary-file smoke passed; the full preparation pipeline was not rerun or current caches relabeled. Raw-file self-hash equality establishes identity with a stored manifest, not provenance independently verified against Census.

## Checks and boundaries

The existing official dictionary defines PWCMPWGT with four implied decimal places, agreeing with division by 10,000. Five-month checks cover December 2018, October 2019, January 2020, November 2022, and October 2026. This is sampled raw regeneration, not a claim that all months were independently reparsed. All 94 selected raw hashes passed the stored manifest check. No plots were displayed and no paid data were used. No main regression was changed by this data audit.

## Empirical occupation-bridge sensitivity

A new youth 47-month FT model retained only unchanged, bijective old-to-new occupation-code links (old=new, both link degrees one, rate one). It rebuilt the same common FT/PT support and specification. The estimate is −4.28% [−11.77, +3.85], p=.292, versus −6.60%, p=.069 in the full primary support. It contains 329 supported occupations and 100,847 cells, retaining 74.85% of primary-support weighted FT employment. The model converged. This addresses one historical coding concern but changes occupation composition, so the attenuation cannot be attributed uniquely to crosswalk error. The sample restriction is a sensitivity, not a corrected primary estimate. Results and code are saved as `stable_code_sensitivity.*`.
