Authenticated collection workflow

  1. The collector opens the required year and page in an existing, authenticated Chrome tab.
  2. It reads the internal Policy Commons artefact identifiers from the rendered search results and removes duplicate identifiers within the page.
  3. Inside the authenticated tab, it submits those identifiers to /api/export/many/ and requests RIS output using the active CSRF token.
  4. Policy Commons returns a short-lived signed export address. Python downloads the RIS payload from that address and does not retain the address or authentication token.
  5. The validated payload is saved as one file per year and page, followed by a manifest record and a restart checkpoint.

This hybrid design is necessary because direct, unauthenticated requests to the search endpoint returned HTTP 403, while export requests made inside the logged-in browser session succeeded. Authentication remains in Chrome; the collector never serialises cookies, passwords or CSRF tokens.

Validation before a page is accepted

Each RIS file must contain at least one record, and its opening TY - markers must equal its closing ER - markers. A response containing more RIS records than the number of requested identifiers, an empty response, or mismatched record boundaries is rejected. Failed pages are retried up to four times with increasing delays.

Policy Commons occasionally returns fewer RIS records than the number of unique identifiers submitted to the export service. The collector preserves these valid records and writes the difference to export_omission_count. This turns a silent provider-side omission into an explicit recovery target rather than discarding the whole page.

Provenance, checkpoints and recovery

Every year has a line-delimited manifest. Each successful page records the UTC retrieval time, year, page number, RIS record count, requested internal identifiers, query address and export omission count. A separate state file identifies the latest successful page, while the log records successes, retries and terminal failures.

Re-running the same command is safe. Before making a request, the collector checks whether the intended page file already exists and passes the RIS boundary test. Valid pages are skipped; missing or invalid pages are collected again. This supports interruption and recovery without overwriting verified output.

Collector source · Reproducibility package

End-to-end cleaning and analysis workflow

  1. Freeze inputs. Save the exact query, modules, content type, publisher type, year filters, sort order, page size, retrieval time and SHA-256 manifest.
  2. Collect paired exports. Save RIS and CSV from the same page and filter state. CSV supplies provider fields such as country and topics that RIS may omit.
  3. Parse and link. Join only normalised Policy Commons identifiers and artefact IDs. Preserve unmatched rows and field-level provenance. Never join by title, filename or row order.
  4. Deduplicate. Resolve stable IDs, canonical URLs, compatible titles, publisher, year, language and content hashes. Keep editions, translations and substantive revisions separate.
  5. Screen AI with high recall. Collection provenance from documented AI-oriented searches is positive evidence. Missing AI terms in exported metadata do not establish Non-AI because Policy Commons may have matched indexed full text. Exclude only clear alternative meanings with positive evidence.
  6. Classify document function. Exclude standalone vacancy notices, product manuals, theses, datasets, course syllabi, media and purely scholarly outputs. Retain official proceedings, workshops and agendas when they contain policy inquiry, regulation, standards, testimony, recommendations or implementation.
  7. Attribute countries. Keep published_in_country, issuer_country, policy jurisdiction and target country separate. Government, public, national commission and publicly funded research evidence can support attribution. Headquarters or repository location alone cannot.
  8. Build the analytical view. Retain unique (record_id, analysis_country) rows with unit weight 1. Assign a document to each supported country without percentage shares. Aggregate HKG to CHN while preserving the original value.
  9. Audit and release. Apply deterministic census rules, preserve exclusion queues, run fixed-seed stratified original-page checks, record inaccessible pages as unverifiable, and publish versioned outputs with manifests and checksums.

Storage, snapshots and governing order

The working design is local first, iCloud second. Downloads is the intake and staging area. The iCloud-backed data3 collection is frozen and processed independently only after the local master passes its gates. Path aliases, symbolic links, file-system identity, size and SHA-256 are compared before counting, so a local path and its iCloud backing path cannot be counted as two sources.

Every RIS, CSV, JSON, JSONL, database and archive is inventoried with path, type, size, modification time, checksum, record count and collection category. The occurrence key is (source_file_sha256, source_record_ordinal). Raw bytes or their hash, parsed-record hash and normalised-content fingerprint remain attached to that occurrence. A later canonical record never replaces this source layer.

The mandatory order is: freeze inputs; validate structure and contamination; parse and normalise; resolve identity and versions; enrich missing fields; classify AI relevance; classify document form; resolve institutions and countries; determine policy eligibility; freeze the local master; process and reconcile iCloud; then release a new integrated version. Every transition records its run, configuration, rules, code and environment versions, counts, timestamps, reviewer actions and checksums.

Identity resolution, versions and field survivorship

The analytical entity is a document version, not an export row. Identity evidence is evaluated in this order: Policy Commons artefact and file identifiers; canonical Policy Commons URL; DOI, ISBN, report number or official publisher URL; finally a reviewed metadata match using title, publisher, year, language and abstract compatibility. Artefact IDs and file IDs are separate namespaces.

An incompatible title or abstract, different language or edition, substantive revision, conflicting typed date, cross-namespace collision or redirect to a collection page blocks automatic merging. Fuzzy title similarity creates review candidates only. Translations, abridgements, annual editions and substantive revisions keep separate record_id values and may be connected through work_cluster_id.

The best structurally valid and internally consistent observation anchors the canonical record. Other observations can fill a missing field through a field-survivorship table, but a non-empty conflict is never overwritten silently. The table records the source occurrence, previous and selected values, rule, confidence and conflict state. This prevents a false composite record assembled from unrelated exports.

Separate classification axes and evidence hierarchy

AI relevance, document form, institution type, policy eligibility and country attribution are separate variables. A government issuer does not make a dataset a policy document; a private issuer does not make an AI report Non-AI; publication place does not establish issuer jurisdiction.

For AI screening, original full text outranks original publisher metadata, which outranks provider summaries, keywords and search provenance. The evidence tiers are E0 no usable evidence, E1 title only, E2 title plus abstract or summary and E3 usable original full text. Missing metadata terms cannot support exclusion. The retained labels are core_ai_policy, substantive_ai_component, incidental_ai_mention, non_ai and unresolved; only a positive, independently auditable basis can support non_ai.

For document form, the normalised labels distinguish policy documents, scholarly articles, patents, government-linked research, hybrid or ambiguous records and unresolved genre. A DOI, university affiliation, the word paper, proceedings or workshop is never sufficient on its own. The decision turns on the document's policy function.

Institution, issuer and country model

The system stores issuer, bibliographic publisher, archive or host, commissioner and adopting government as different relations. The institution authority table contains the canonical name, aliases, institution class, governmental relationship, country, evidence URL, validity period, confidence and verification date.

National and subnational governments, legislatures, regulators, statutory agencies, public research institutes, official committees and qualifying public policy institutes enter the national-policy group. International organisations, EU bodies, independent think tanks, foundations, universities, corporations, networks and repositories remain separate. A non-government body can enter a government-linked layer when formal commissioning, adoption, funding or co-issuance is demonstrated.

Country concepts are not collapsed. The release retains published_in_country, issuer_country, policy_jurisdiction, target_country and author-affiliation country. The analytical code CTRY follows verified issuer jurisdiction. Reserved non-country codes are XIG for intergovernmental organisations, XEU for EU institutions, XMN for multinational private issuers and XUN for unresolved cases. Multiple eligible issuers are represented in link tables, not fractionalised. HKG is aggregated to CHN only in the analytical view; the observed value is retained.

Release package, invariants and deletion gate

A release contains the canonical master, source provenance, collection routes, duplicate and work-cluster maps, institution authority, document-country links, quarantine, exclusions, unresolved records, stage counts, scripts, environment information and SHA-256 manifests. Core grains are enforced with primary and foreign-key checks so many-to-many joins cannot inflate analysis rows.

Required accounting identities include: raw observations equal accepted parses plus parse quarantine; accepted parses equal linked observations plus unresolved identities; linked observations equal canonical anchors plus duplicate links; canonical records equal accepted master records plus exclusions, unresolved classifications and conflict quarantine.

Physical deletion is never a cleaning shortcut. It requires a frozen source manifest, persisted and checksummed canonical or exclusion record, reconciled counts, reviewed dry run, exact-path deletion manifest, recoverable quarantine, immediate pre-deletion size and checksum verification, recorded approval, successful restore test and completed iCloud synchronisation. No physical source deletion was performed for the current release.

A document may show Published in Serbia while its issuer is the Government of Kosovo. Preserve both fields, but assign the analytical country from explicit issuer jurisdiction. Example: multinational private firm

An Abbott document labelled Abbott (United States) preserves USA as source evidence but is excluded from the national policy-interest view unless government commissioning, funding or a national research remit is demonstrated. A headquarters location alone is insufficient.

RIS–CSV and duplicate errors

RIS can omit page fields such as country and topics. Always collect the paired CSV and join only normalised Policy Commons and artefact identifiers. Preserve unmatched and conflicting keys. Never join by title, filename or row order. Deduplicate with stable IDs, canonical URLs, compatible title, publisher, year, language and content evidence. Keep editions, translations, annual editions and substantive revisions separate.

AI false negatives and ambiguous terms

Metadata absence is not Non-AI because the provider can match indexed full text. Retain records from documented AI-oriented searches unless positive evidence establishes an alternative meaning. Exclude avian influenza, air, biological neural networks and similar collisions only when no independent computational-AI evidence remains. Historical terms such as expert systems, machine intelligence and intelligent systems require computational context. Record query provenance, evidence location and AI centrality separately.

Document-form errors and corrections

Standalone vacancy notices, position descriptions, product or user manuals, theses, datasets, course syllabi, videos and images are excluded from the policy-document view. Government or public ownership does not rescue a non-policy format. Exceptions require an explicit policy function: legal or regulatory implementation guidance, official curriculum or examination specification, commissioned policy evidence, or a substantive mixed document.

Proceedings, workshops and agendas are not excluded by title. Retain official government inquiries, parliamentary hearings, regulatory or standards work, testimony, recommendations, action plans and implementation records. Exclude only logistical event records and purely scholarly proceedings. Human review of 136 records confirmed this rule.

Country-attribution errors

Store published_in_country, issuer_country, policy jurisdiction and target country separately. Explicit issuer jurisdiction overrides a conflicting place, as in Government of Kosovo versus Published in Serbia. Public libraries and national commissions can be genuine issuers. EU, international organisations, repositories and headquarters locations are not national issuers without a supported national office, commission or country-specific mandate. HKG is mapped to CHN for analysis while raw values remain preserved.

Multinational private institutions

A headquarters or branch location alone does not represent national policy interest. Ordinary business, product and promotional documents from multinational firms are excluded from the national analysis but retained in the source master. A private research unit is included only when the source demonstrates government commissioning, funding or a national research remit. Unclear cases remain manual_review.

Sampling and original-page verification

Freeze a seed and frame before sampling. Use strata for suspected boundary documents, confirmed contamination and an ordinary negative control. Record N_h, n_h, inclusion probability and design weight. Open the original Policy Commons page with production labels hidden where feasible. Record actual form, policy function, issuer, year, AI evidence, URL, evidence quote, access status and adjudication. An inaccessible page is unverifiable, never an automatic pass.

Review sampling tests already completed

Country-page audits used non-overlapping fixed-seed samples of 100 records with seeds 20260920, 20260921, 20260922, 20260923 and 20260924. Each selected Policy Commons page was opened and its publication-country value was compared with the classified country after issuer exceptions. The document-form review used 400 records: 200 suspected boundary records (seed 20260925), 100 confirmed-contamination records (seed 20260926) and 100 ordinary negative controls (seed 20260927). IDs and URLs were unique, samples did not overlap earlier samples, and manifests were byte-reproducible. Human review retained official policy proceedings and confirmed exclusion of standalone datasets, theses, videos and syllabi. These samples validate implementation and identify error types; they are not treated as a full-population semantic accuracy estimate.

Release and regression gate

Apply only deterministic rules with a positive example, a counterexample and no confirmed false exclusion. Report document counts and document-country row counts separately; require unique pairs and unit weights of 1. Preserve the source master, exclusion register, manifests, code, environment, sample files and SHA-256 checksums. Create a new versioned release rather than overwriting a prior release.

Interpretation and limitations

The search filters improve precision but do not establish that every retrieved item is a national policy report. Organisation type, issuing body, jurisdiction and document function must still be classified after collection. International organisations should remain separate from national portfolios, and local or regional government publications should retain their administrative level.

Database coverage, metadata and result counts can change. Reproduction therefore requires the recorded configuration, retrieval date and manifests. RIS files are not published in the GitHub repository because access and redistribution remain subject to the user's Policy Commons licence.

The final pair file contains 222 rows without a year. Observed numeric years span 1601–2026, so historical extreme values require a separate temporal-outlier review before longitudinal analysis. The completed samples were designed primarily for implementation checks and discovery of error families. Without stratum-level adjudicated outcomes and weighted confidence intervals, they do not establish a population-wide semantic accuracy rate.
