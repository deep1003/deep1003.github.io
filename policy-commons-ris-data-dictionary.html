Policy Commons Integrated RIS and CSV Data Dictionary

Variable definitions for pcgs-aigov5-golden-v1, the identifier-linked Golden Set candidate built from Policy Commons RIS and CSV exports. The analytical grain is one unique Policy Commons document identified by both its normalised persistent content identifier and numeric artefact identifier.

Scope. The master contains only exact RIS–CSV pairs satisfying normalise(CSV.coi) = normalise(RIS.ID) and artifact_id(CSV.url) = artifact_id(RIS.UR). Title, page number and row position are never substitute join keys.

Usage rules

  • Use record_id for internal analysis and (join_coi, join_artifact_id) for cross-format integrity checks.
  • Do not equate published_in_country_* with issuer_country.
  • Do not replace keywords or topics with topics_combined when field provenance matters.
  • Use country_analysis_eligible for the current rule-based national analysis. Reassess it if country rules change.
  • Treat human_validation_status = pending records as Golden Set candidates, not fully adjudicated ground truth.
Temporal reproducibility. Policy Commons holdings and artefact identifiers may change. Reproducing the exact counts requires the frozen RIS and CSV inputs and manifests. Re-running the same live query later reproduces the method, not necessarily the same provider snapshot.

Snapshot date: 20 September 2026. Method: Paired RIS and CSV collection and Golden Set construction. Country rules: Policy Commons country-attribution protocol.
