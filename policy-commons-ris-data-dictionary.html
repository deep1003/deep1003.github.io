Collection and cleaning workflow / Data dictionary

Policy Commons augmented master v7.10 data dictionary

The column names, order and physical types are generated from the Parquet schema of policycommons_augmented_master_final_v7_10.parquet. Definitions combine manually curated descriptions for core fields with documented prefix-based descriptions for versioned audit fields. It describes all 162 stored columns. The master grain is one canonical document version.

Authoritative analytical table. Country-level analysis must use document_country_pairs_final_v7_10.csv and its unique (record_id, analysis_country) rows. Do not reconstruct the release by filtering CTRY, analysis_country_final or other master columns. Base, intermediate and final fields coexist to preserve correction history, and the inherited release_version value inside the master predates the v7.10 directory-level release identity.
